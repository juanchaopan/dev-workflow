{{一句话：这份设计覆盖哪些需求，例如"第一版（MVP）的全部需求"。}}

这张一览表也是设计的进度表：/design 做一个元素改一个状态，中断以后再运行 /design，会从第一个没确认的元素接着做。

状态的含义：

- 未开始、进行中：还在设计。
- 已确认（YYYY-MM-DD）：用户逐个确认过。
- AI 设计，待确认：AI 做完了、用户还没看，开发前必须先请用户确认。
- 已实现，从代码整理：从现有代码整理出来的现状。
- 已废弃：保留编号，不再使用。
